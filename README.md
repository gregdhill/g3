# G3

G3 — a minimal fork of T3 Code (MIT): a flat list of chats (no projects) with a terminal drawer. Desktop + web.

## Development

```sh
vp i                 # install dependencies
vp run dev           # server + web
vp run dev:desktop   # Electron desktop app
```

State lives in `~/.g3` (override with `T3CODE_HOME`); dev state goes to `~/.g3/dev`.
